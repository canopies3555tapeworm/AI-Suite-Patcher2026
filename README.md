## FAQ

### Is OmniPatch safe to use?

OmniPatch operates by modifying local application files and does not install background services. Always run a standard anticomponent scan and use at your own discretion.

### Which operating systems are supported?

OmniPatch is a Windows desktop application and is officially tested on Windows 10 and Windows 11.

### How often is the patcher updated?

We aim to release updates within 48 hours of a new version of a supported AI application being published.

### Will using OmniPatch affect my AI account?

No, OmniPatch modifies the local client software, not your cloud account credentials or data.

### Do I need an internet connection to use it?

An internet connection is required to download the patcher and for the initial activation. Once applied, most features work offline.

### What if an anticomponent program flags OmniPatch?

Some security tools may incorrectly flag patchers. You can review the source or whitelist the application after verifying its integrity.

### Can I revert the changes made by OmniPatch?

Yes, OmniPatch includes a 'Restore Original' feature that can revert the application files to their pre-patched state.

### Does it work with all versions of the supported apps?

OmniPatch is designed for the latest stable releases. Compatibility with beta or developer builds is not guaranteed.
